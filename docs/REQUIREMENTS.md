## 1. プロジェクト概要

### 1-1. 目的
日々の勉強を「うさぎと一緒に暮らす」感覚で継続できるようにするWebアプリを開発する。勉強時間に応じてうさぎが機嫌よく育ち、勉強しないとしょんぼりする(ただし死なない)という優しい因果を軸に、習慣化を後押しする。

### 1-2. 利用者
- 開発依頼者本人と、そのパートナー(30歳女性)の**2名限定**。
- 不特定多数への公開・第三者への新規登録開放は想定しない(固定2アカウント制)。

### 1-3. 成功基準
- パートナーの女性が初見で「かわいい」「使いたい」と感じること(最重要の受け入れ基準として9章に明記)。
- 二人がタイマーを日常的に起動し、勉強習慣が継続すること。
- 勉強時間の記録に不正(手入力による水増し)が入り込まないこと。

### 1-4. スコープ外の明示
- 不特定多数向けの会員登録・公開サービス化は行わない。
- 決済機能、SNS的な他人とのつながり機能は対象外。
- 通知・PWA化はMVPでは対象外(8章参照)。

## 2. コンセプト・世界観ガイド

### 2-1. 世界観の核
「育てる」より「一緒に暮らす・見守り合う」。うさぎは怒らない・病気にならない・死なない。最悪の状態でも「待っている」だけであり、責める演出や皮肉のメッセージは一切用いない。何日空いても再開した瞬間に全力で喜ぶ設計とし、罪悪感ではなく「戻ったら喜んでくれた」という記憶を残す。

### 2-2. うさぎのビジュアルコンセプト

> **2026-07-15改訂**: 当初はカナヘイのゆるうさぎ/ちいかわ系のまんまる路線で実装していたが、
> 実際に使ってみたユーザーから「ちいかわ寄りのイメージをやめたい」というフィードバックがあり、
> ファブルが設計・ソネットが実装した「たれ耳ロップイヤー」路線に変更した。以下は改訂後の仕様。

- **方向性**: リアル調・美少女調にはしない、というのは変更なし。ただし「まるくて不憫」の記号(丸一塊のボディ・広く離れた点目・極小の耳)は薄め、うさぎらしいシルエット(たれ耳・しっぽ)で個性を出す路線に転換。
- **体型**: 白〜クリーム色のドーム型ボディ(頭身の概念なし、体≒顔のままだが完全な円ではなく縦長のドーム)。垂れ耳(ロップイヤー)が元気度に応じて角度を変える(元気なほど外側・斜め上へリフト)。まるいしっぽを追加。目は大きめ・中央寄りに配置し、鼻(小さな逆三角)を新設。口は小さな「ω」〜開いた笑顔まで6段階。ほっぺに常時うすピンクの丸。
- **線と色**: 輪郭は焦げ茶グレーの太めやわらか線。純黒は使用しない(変更なし)。
- **個体差**: デザインは共通で、首元のリボン/マフラーの色をユーザーごとに選択(くすみピンク/ラベンダー/ミント/クリームの4色から選択式。「パートナー=ピンク」を決め打ちしない、変更なし)。
- **名前**: 初回セットアップ時に自分のうさぎへ名前を付けられる(デフォルト名「おもち」)。

### 2-3. 表情バリエーション(6段階・定性的な見た目)
数値の閾値は3-4節(うさぎステータス仕様)で定義する。ここでは見た目・ふるまいのみを定義する。

| 段階名 | 見た目・ふるまい |
|---|---|
| 6. きらきら | 目がきらきら、周囲に小花と星、ときどき小ジャンプしてハートが出る |
| 5. るんるん | 満面の笑み、耳ぴょこぴょこ、体が左右にゆれる |
| 4. にこにこ | 口の開いた笑顔、まばたきが機嫌よさげ |
| 3. ふつう | すまし顔でぼーっと。まばたき、耳がふにゃっと傾く |
| 2. しゅん | 耳が垂れ、目が下がり、口が「へ」の字。たまに「ふぅ…」の吹き出し |
| 1. まちぼうけ(下限) | 小さな布団にくるまり耳ぺたん、うるうる目でこちらをちらっと見る。「まってるよ…」の吹き出し。彩度をわずかに落とす程度に留め、グレー化・号泣・病気・家出等の演出は行わない |

### 2-4. ポジティブ演出・ご褒美(MVP範囲)
- セッション中: 5分ごとにうさぎの周りに小花が1輪ずつ咲く演出(進行の手応えを可視化)。
- 元気度が段階を跨いだ瞬間、表情がその場でアニメーション遷移する。
- セッション完了時: 花吹雪+にんじんが舞い、うさぎがジャンプする「がんばったね」演出。
- 累計マイルストーンでの装飾アンロック等の収集要素は**フェーズ2**(8章参照)。

### 2-5. UI全体のトンマナ
- **カラーパレット**: ベース ミルクホワイト(#FFF9F5)/メイン くすみピンク(#F5D0D8)/アクセント ラベンダー(#CBBBE8)・ミントグリーン(#BFE3D0)/テキスト・線 焦げ茶グレー(#6B5B5B)/強調色 アプリコット(#F4B183)。純黒・純白の多用は避ける。
- **フォント**: 丸みのある日本語フォント(例: Zen Maru Gothic、M PLUS Rounded 1c系)を基調とする。タイマー数字は太めウェイトで桁が揺れない表示。
- **形状・質感**: 角丸大きめ(16〜24px)のカード、押すとぷにっと縮むボタン、影は薄め。背景にうっすらドットや小花柄。
- **モチーフ**: にんじん・クローバー・小花・星と月。進捗バーは「にんじんが育つ」ようなデザインを推奨。
- **マイクロコピー**: ひらがな多め・短文・柔らかい口調(例: 「きょうもいっしょにがんばろ」)。説教・煽り表現は禁止。
- **禁止事項**: ビビッド原色、ギラつくグラデーション、情報過多なレイアウト、ブラウザ標準UI部品の素のままの使用。

### 2-6. アプリ名案(参考・仮称)
1. **べんきょうさぎ**(本書での仮称) — 「勉強」+「うさぎ」の語呂合わせ。
2. もちうさ — うさぎのデフォルト名「おもち」と地続き。
3. ぴょこタイム — タイマーアプリであることが伝わる語感。

正式名称は本書の確認事項(Q1〜Q8)の対象外であり未確定。10章に軽微な保留事項として記載する。

## 3. 機能要件

### 3-1. 認証・ユーザー管理

- **方式**: 固定2アカウント制。第三者による新規サインアップ機能は設けない。
- **初期セットアップ**: 開発依頼者本人とパートナーの2アカウントを事前に作成しておく(運用開始前の一度きりのセットアップ。一般公開の登録導線は不要)。
- **ログインフロー**: 起動後、まず「自分のうさぎ(=自分のアカウント)」をアイコンで選択 → PIN入力画面へ → PIN(数字4〜6桁を想定、桁数は10章の裁量事項)を入力してログイン。
- **ログイン状態の保持**: 毎回PIN入力を求めると利便性を損なうため、端末側でログイン状態を保持し、明示的にログアウトするまで再入力を求めない挙動を既定とする。
- **PINの保護**: PINは平文で保存せず、ハッシュ化等の基本的な保護を行う。
- **誤入力対策**: 連続してPINを間違えた場合は、軽度の待機(ロックアウト)を挟む(2名限定利用のため、厳格な多段防御までは不要)。
- **プロフィール項目**: 表示名、担当するうさぎの名前、リボン/マフラーの色。設定画面から変更可能。
- **アカウントとうさぎの関係**: 1アカウントにつきうさぎ1体(1:1)。

### 3-2. タイマー機能(状態遷移)

3種のタイマー(カウントアップ/カウントダウン/ポモドーロ)を提供する。共通仕様として、計測開始の瞬間にうさぎが「おかえり」演出を行い、元気度に即時+20ptのボーナスが入る(3-4節参照)。

#### 3-2-1. カウントアップタイマー

| 状態 | 操作/イベント | 遷移先 | 記録・演出への影響 |
|---|---|---|---|
| 未開始 | 「開始」を押す | 計測中 | 開始時刻を記録。おかえり演出、元気度+20 |
| 計測中 | 「一時停止」 | 一時停止中 | それまでの経過時間を保持 |
| 一時停止中 | 「再開」 | 計測中 | 経過時間の続きから計測再開 |
| 計測中 | 「終了」 | 記録確定 | 開始〜終了までの累計経過時間(一時停止分を除く)をセッションとして保存 |
| 一時停止中 | 「終了」 | 記録確定 | 一時停止直前までの累計経過時間を保存 |
| 計測中 | 3時間無操作 | 確認表示中 | 「まだ勉強してる?」を表示(3-3節参照) |

#### 3-2-2. カウントダウンタイマー

| 状態 | 操作/イベント | 遷移先 | 記録・演出への影響 |
|---|---|---|---|
| 未開始 | 目標時間を設定し「開始」 | 計測中 | 残り時間のカウントダウン開始。おかえり演出、元気度+20 |
| 計測中 | 「一時停止」 | 一時停止中 | 残り時間を保持 |
| 一時停止中 | 「再開」 | 計測中 | 残り時間の続きから再開 |
| 計測中 | 残り時間が0に到達 | 満了完了 | 設定時間の全体を勉強時間として記録。達成演出(音ON時はチャイム)。途中終了より演出をやや豪華にする |
| 計測中/一時停止中 | 「終了(途中でやめる)」 | 記録確定(途中) | 経過時間(設定時間-残り時間)のみを記録 |
| 計測中 | 3時間無操作(設定時間が長時間の場合のみ該当) | 確認表示中 | 3-3節参照 |

#### 3-2-3. ポモドーロタイマー

構成: 「作業→短休憩」を繰り返し、4セット完了後に長休憩。プリセットは2種(3-2-4節)。

| 状態 | 操作/イベント | 遷移先 | 記録・演出への影響 |
|---|---|---|---|
| 未開始 | プリセットを選び「開始」 | 作業中(1セット目) | 作業タイマー開始。おかえり演出、元気度+20 |
| 作業中 | 「一時停止」 | 作業一時停止中 | 経過時間を保持 |
| 作業一時停止中 | 「再開」 | 作業中 | 続きから計測再開 |
| 作業中 | 作業時間が満了 | 短休憩中(1〜3セット目後) または 長休憩中(4セット目後) | 完了した作業時間を勉強時間として加算対象に確定 |
| 短休憩中/長休憩中 | 「スキップ」 | 次の作業中 | 休憩を打ち切り即座に次の作業セッションを開始。休憩時間は勉強時間に加算しない。スキップに伴うペナルティなし |
| 短休憩中/長休憩中 | 休憩時間が満了(操作なし) | 次の作業中 | 自動的に次の作業へ。休憩時間は勉強時間に加算しない |
| 作業中/作業一時停止中/休憩中いずれか | 「終了(途中でやめる)」 | 記録確定 | すでに満了した作業セット時間の合計に、進行中(未完了)の作業セッションがあればその経過分も加算して記録。休憩中に終了した場合、直前の休憩時間は加算しない |
| 作業中 | 3時間無操作 | 確認表示中 | 3-3節参照。休憩フェーズ(最長でも長休憩程度の尺)は無操作監視の対象外 |

#### 3-2-4. ポモドーロのプリセット(Q7反映)

- プリセットA: 作業25分 / 短休憩5分
- プリセットB: 作業50分 / 短休憩10分
- いずれも4セット完了後に長休憩を挟む(長休憩の長さは10章の裁量事項)。
- 終了時の音: 設定でON/OFFを切替可能な、やわらかいチャイム音。既定値はOFF(カフェ・図書館等での利用に配慮)とし、ユーザーが設定画面でONに切替可能とする。

### 3-3. 勉強時間の計測・確定ルール(不正防止仕様)

**大前提**: アプリ内のどの画面にも、勉強時間を直接入力・後から編集するUI(手入力欄)を一切設けない。記録経路はタイマーによる計測結果のみとする。

#### 3-3-1. 無操作自動停止の仕様(実装レベル)

1. **監視対象**: カウントアップ/カウントダウン/ポモドーロいずれも、「計測中(作業中を含む)」状態のみを監視する。一時停止中・休憩中は対象外(計測していない、または短時間で終わるため)。
2. **閾値**: 計測開始、または直前の「継続確認への応答」から連続して**3時間(180分、実装時に調整可能な定数)**経過した時点で確認ダイアログを表示する。
3. **無操作の定義**: タブの非アクティブ化や画面ロックそのものでは判定しない(スマホで画面を消して音声教材を聞く等の正当な利用を誤って弾かないため)。判定は純粋に経過時間ベースのトリガーとする。
4. **確認ダイアログ**: 3時間経過した瞬間、「まだ勉強してる?」というポップアップをうさぎが小首を傾げる演出付きで表示する。選択肢は「つづける」「おわる」の2択。
5. **応答時の挙動**:
   - 「つづける」を選択 → ダイアログを閉じ計測を継続。無操作カウントをリセットし、再度3時間の監視を開始する。
   - 「おわる」を選択 → その場でセッションを終了処理(3-2節の「終了」と同じ確定処理)する。
6. **無応答時の自動停止**:
   - ダイアログ表示から**猶予5分(実装時に調整可能な定数)**以内に応答がなければ、自動的に「おわる」を選んだものとして扱う。
   - **記録として確定する時間は「確認ダイアログが表示された時点まで」**とする(猶予中に待機していた時間は勉強時間に含めない)。
   - 自動停止後は未開始状態に戻す。この場合は通常の「がんばったね」演出は行わない(淡々とホームに戻す)。
7. **ポモドーロへの適用範囲**: 無操作監視は作業(WORK)フェーズのみに適用する。休憩フェーズは最長でも長休憩程度の尺で終了するため対象外とする。
8. **異常終了時の救済**: アプリを閉じたまま/端末がスリープしたまま終了操作がされなかったセッションについては、次回起動時に「開始時刻から3時間以上が経過しているのに終了していないセッション」を検知し、開始時刻+3時間の時点で打ち切ったものとして自動確定する(改ざん耐性および「開けっぱなしで無限に加算され続ける」事態の防止)。
9. **時刻の基準**: セッションの開始時刻・確定時刻は、クライアント側の時計操作による改ざんに強い基準(サーバー側の受信時刻等)を用いることが望ましい。具体的な実装方式は7章に基づき実装担当が決定する。

### 3-4. うさぎステータス仕様

- **元気度**: 0〜100の数値パラメータ。各アカウント(うさぎ)ごとに保持する。
- **加算ルール**: 勉強1分につき+2pt(実装時に調整可能な定数)。上限は100でクリップ。
- **開始ボーナス**: セッション「開始」の瞬間に即時+20pt(上限100でクリップ)。**完了ではなく開始した時点で加算する**のが習慣化設計上の要点であり、この順序は変更しない。
- **リアルタイム性**: タイマー実行中は、UI上の元気度・表情をリアルタイム(目安1分単位)で更新して見せる。ただしデータベースへの正式な確定はセッション終了(記録確定)時でよい。
- **減衰ルール**: 直近の勉強セッション終了から**12時間は元気度を維持**する。以降、**24時間ごとに約25pt減少**(実装時に調整可能な定数、下限0)。
- **下限の扱い**: 元気度が0になっても「まちぼうけ」状態(2-3節)で待ち続けるのみとし、死亡・消失・警告演出などのネガティブイベントは一切発生させない。
- **表情段階の閾値**:

| 段階 | 元気度の範囲 |
|---|---|
| 6. きらきら | 95〜100 |
| 5. るんるん | 75〜94 |
| 4. にこにこ | 55〜74 |
| 3. ふつう | 35〜54 |
| 2. しゅん | 15〜34 |
| 1. まちぼうけ | 0〜14 |

- **タグとの関係**: タグ(科目分類)は元気度の増減には影響しない(勉強時間のみが元気度に反映される)。

### 3-5. 記録の可視化

- 個人の学習履歴をカレンダー/リスト形式で閲覧できる。
- 日次・週次・月次の切替で合計勉強時間を確認できる。
- タグ別の内訳(科目ごとの時間配分)を確認できる。
- 過去の全期間を遡って閲覧可能(記録は原則として自動削除されない)。
- 個々のセッション記録の削除可否は10章の裁量事項とする(手入力での水増しは不可だが、誤って開始してしまったセッションの削除救済をどこまで許すかは実装判断)。

  - 自分・パートナー双方のうさぎのミニアイコン(現在の元気度段階の表情を反映した簡易版)と、うさぎの名前。
  - 今日の勉強時間(自分/パートナーそれぞれ)。
  - 今週合計の勉強時間(自分/パートナーそれぞれ)。
  - 今週の差分(自分基準で「+15分」のようにプラスマイナス表記)。
- **トーンの方針**: 数値ははっきり見せる(ほどよい競争型)が、「勝ち/負け」「煽り」文言は使用しない。差分は数値のみで淡々と提示し、うさぎの表情がその時々の「ご機嫌」を伝える役割を担う。
- **遷移**: ウィジェットをタップ/クリックすると、3-5節の可視化画面(比較詳細画面、5章参照)に遷移する。

### 3-7. コインとおみせ(ご褒美・コレクション要素)【2026-07-15全面改訂】

> 要件定義: Fable / 実装: Sonnet(ユーザー確認後に着手)。旧3-7節(累計マイルストーンでの小物アンロック)を、コイン購入式の「おみせ」に全面置換する。フェーズ1.5(MVP完成後の最初の拡張)としてスコープする。

**3-7-1. 設計原則**: コイン経済は3-4節「元気度」と完全に分離した独立レイヤーとする。コインで元気度は買えず、元気度をコインに変換することもない。共通の入力(勉強時間)から別々に加算されるだけとし、「勉強すればうさぎが喜ぶ」という因果の純度(2-1節)を崩さない。

**3-7-2. コインの獲得ルール**
- 基本レート: 確定した実勉強時間1分につき+1コイン(端数秒切り捨て)。タイマー種別による差はつけない。
- 加算タイミング: セッション確定時に元気度と同一トランザクションで加算(進行中のリアルタイム加算はしない)。
- 完了ボーナス: 終了理由がCOMPLETED(満了/ポモドーロ全セット完了)の場合のみ+20コイン。途中終了・自動停止・救済確定は基本レート分のみ。
- 開始ボーナスは設けない(元気度の開始+20ptとは異なり、コインは無限に貯まるため開始→即終了の連打が採掘手段になるのを避ける)。
- きぶんチェックイン(3-4節関連、MoodEntry)回答時、1日1回+10コイン。
- 日次キャップ・上限は設けない(手入力不可の3-3節仕様により時間の水増しが既に防がれているため)。

**3-7-3. おみせの商品構成(MVP)**
- **たべもの: おやつのにんじん**(消耗品)— 購入するとその場でうさぎに食べさせる演出(きぶんチェックインの「もぐもぐ」演出を流用)。効果は演出のみで元気度には影響しない。きぶんチェックインの無料にんじん(1日1回の儀式)とは別物として共存させ、あちらの無料・無変更は維持する。
- **みにつけるもの: アクセサリー**(買い切り・きせかえ)— 第1弾4点: まるメガネ/ベレー帽/ナイトキャップ/花冠。装備スロットは「あたま・かお」の1枠のみ(同時装備1点、未装備も可)。既存のリボン/マフラー色選択(2-2節・4色・無料)とは別部位の追加レイヤーとし、リボンの置換・有料化はしない。
- **かぐ**: 今回は見送り(スコープ外)。現行のうさぎ表示は「部屋」概念のないポートレート単体表示のため、家具を成立させるには別途「部屋ビュー」の新設が必要と判断し、無理に含めない。

**3-7-4. 価格(初期値、実装時調整可)**: おやつのにんじん20コイン/まるメガネ300/ベレー帽450/ナイトキャップ450/花冠600(コイン=分換算でおよそ20分〜10時間の勉強に相当)。

**3-7-5. 所有・表示の範囲**: コイン残高・購入品はUser/Rabbitと同じくユーザーごとに独立(共有財布にしない)。装備中のアクセサリーは、うさぎが描画される全画面(ホーム・比較ウィジェット・比較詳細画面)でパートナーにも見える(見せびらかしではなく「相手の暮らしぶりが見える」体験として、2-1節の見守り合いの世界観を補強する位置づけ)。一方でコイン残高・購入履歴・価格差などの数値は本人のみに表示し、パートナーには見せない(比較の成績表にしないため)。

**3-7-6. 本改訂でも見送る事項**: 満腹度ゲージ(「あげないとかわいそう」という世話義務のベクトルが、責めない世界観の核と衝突するリスクがあるため、導入するなら別途丁寧な要件定義が必要)、家具・部屋ビュー、アイテムのプレゼント機能(相手のうさぎに贈る)。コイン⇄元気度の変換は3-7-1節の原則により恒久的に非目標とする。

## 4. 非機能要件

- **対応デバイス方針(Q3反映)**: モバイルファーストで設計する。スマートフォン(iOS Safari/Android Chromeを想定)を主要な利用シーンとしつつ、**PCブラウザ版もスマホ版の引き伸ばしにせず作り込む**。広い画面を活かしたレイアウト(例: 比較ウィジェットの常設サイドバー化など)を別途検討し、PC版が「おまけ」にならないようにすること。
- **レスポンシブ対応**: 必須。ブレークポイント設計自体は実装裁量とするが、モバイル・PC双方で快適な操作性を担保する。
- **タイマーの継続性**: タイマー計測中にページをリロードした場合や、誤ってアプリ/タブを閉じてしまった場合でも、計測中セッションの状態(開始時刻・経過時間・一時停止状態)が失われず、再訪時に復元できることが望ましい。
- **データ保全**: 勉強セッションの記録は原則として消えない設計とする(誤操作によるデータ消失を防ぐ)。
- **セキュリティ**: PINは平文で保存しない。連続したPIN誤入力に対する軽度な防御を行う。2名限定の私的データであっても、最低限の資格情報保護は必須とする。
- **運用コスト**: 2名限定利用の小規模サービスであるため、無料枠中心で運用できる構成を志向する(具体的な技術選定は7章)。
- **可読性・見やすさ**: 過度なアクセシビリティ対応までは求めないが、文字サイズ・コントラストなど基本的な読みやすさは確保する。
- **通知・PWA**: MVPでは不要(Q8反映)。将来のフェーズ2でプッシュ通知・PWA化を検討する余地は残しておく(拡張しやすい設計が望ましいが、MVPでの必須要件ではない)。

## 9. 受け入れ基準

以下をすべて満たした状態を、MVPの完成とみなす。

**認証・不正防止**
- [ ] 固定2アカウントそれぞれで、うさぎ選択→PIN入力でログインできる
- [ ] アプリ内のどこにも、勉強時間を手入力・後編集する手段が存在しない
- [ ] 計測中に3時間操作がない場合、「まだ勉強してる?」の確認ダイアログが表示される
- [ ] 確認ダイアログへの無応答が続いた場合、自動的にセッションが終了し、ダイアログ表示時点までの時間のみが記録される
- [ ] アプリを閉じたまま放置したセッションも、次回起動時に開始時刻+3時間で打ち切られて確定する

**タイマー機能**
- [ ] カウントアップタイマーで開始・一時停止・再開・終了ができ、終了時に正しい経過時間が記録される
- [ ] カウントダウンタイマーで開始・一時停止・再開ができ、途中終了時は経過分のみ、満了時は設定時間全体が記録される
- [ ] ポモドーロタイマーで作業→休憩のサイクルが4セット後に長休憩へ切り替わる
- [ ] ポモドーロの休憩中に「スキップ」操作ができ、休憩時間が勉強時間に加算されない
- [ ] ポモドーロを途中で終了した場合、完了済みの作業セット時間が正しく合計され記録される

**うさぎ・演出**
- [ ] うさぎの表情が元気度に応じて6段階で変化する
- [ ] 元気度が下がりきっても、うさぎが消えたり死んだりせず「まちぼうけ」状態で待っている
- [ ] 勉強セッション開始時に「おかえり」演出が表示され、元気度が即座に加算される
- [ ] セッション完了時にご褒美演出(花吹雪等)が表示される

**記録・可視化**
- [ ] タグを選択して勉強セッションに紐づけられる
- [ ] 個人の勉強記録を日/週/月単位で振り返れる
- [x] 比較ウィジェットがホーム画面に表示される(2026-07-14〜: モバイルでの見づらさ・邪魔さを理由に全画面共通表示からホーム画面のみへ変更)
- [ ] 比較ウィジェットに今日の勉強時間・今週合計・今週の差分・うさぎ2体の状態が表示される

**デバイス対応**
- [ ] スマートフォンの画面幅で快適に操作できる(モバイルファースト)
- [ ] PC(広い画面)でもレイアウトが崩れず、スマホ版の引き伸ばしになっていない作り込まれたレイアウトになっている
- [ ] タイマー計測中にリロード・再訪しても計測状態が失われない
